#+title: linux-rg kernel support for the GrokOS session plane
#+date: [2026-08-19 Wed]

* What GrokOS is (kernel view)

GrokOS is a same-uid session plane: =sessiond= is a Cap'n server on an
=AF_UNIX= socket, =grokos-shell= is the seat, agents are Cap'n clients.
Instant work never waits on a model. Supervised goals are admitted from
host PSI, spawned as isolated processes, and torn down with
=cgroup.kill= plus a process-group fallback.

The kernel does not grow a GrokOS syscall. It has to keep the knobs that
plane already uses.

| Seat need | Kernel surface |
|-----------|----------------|
| Goal admit / defer | =/proc/pressure/{cpu,memory,io}= (=CONFIG_PSI=) |
| Hardware pressure | =/sys/class/{power_supply,thermal,drm,input}= |
| Goal leaf stop | cgroup v2 =cgroup.kill= on =grokos-goal-*= |
| Frequent leaf create/destroy | =CONFIG_CGROUP_FAVOR_DYNMODS= |
| Jail (=bwrap --unshare-user/pid/uts/ipc/cgroup=, optional net) | user/pid/uts/ipc/cgroup/net namespaces + tmpfs |
| Session event ring | =memfd_create= |
| Same-uid ACL | =SO_PEERCRED= on =CONFIG_UNIX= |
| Later FS sandbox | Landlock LSM |
| Expert scheduler switch | =CONFIG_SCHED_CLASS_EXT= + ASA (=seat_cgroup= PSI) |
| IRQ-subtracted CPU time | =CONFIG_IRQ_TIME_ACCOUNTING= |
| Optional warm process restore | CRIU (=CONFIG_CHECKPOINT_RESTORE= plus sock-diag / uffd / soft-dirty) |

* Overlay pin

All three profiles (=rgx1gen11.config=, =rgam5terra.config=,
=rgSURFLat.config=) pin the seat set. Arch =config.x86_64= already
enables most of it; the overlay makes =CONFIG_CGROUP_FAVOR_DYNMODS=y=
and repeats the rest so a slim =localmodconfig= cannot drop them.

=scripts/linux-rg-grokos-seat-check= asserts the pin.
=scripts/linux-rg-criu-check= asserts the CRIU set.

* CRIU

CRIU (criu.org) freezes a process tree to disk images and restores it.
GrokOS can use that for optional warm restore of a seated agent; cold
resume (session files + Cap'n) stays the default. The kernel job is
the kconfig surface. Dump, restore, and image sealing stay in
userspace.

Overlays pin the official required set as builtins so a
=localmodconfig= cannot drop them and a dump does not depend on
sock-diag modules being loaded:

| Knob | Why CRIU needs it |
|------|-------------------|
| =CHECKPOINT_RESTORE= / =KCMP= / =PROC_CHILDREN= | pid reuse, task compare, children |
| namespaces + =SYSVIPC_SYSCTL= | bwrap jail + IPC restore |
| =FHANDLE= / =EVENTFD= / =EPOLL= | open-by-handle and event fds |
| =UNIX_DIAG= / =INET_DIAG= / =INET_UDP_DIAG= / =PACKET_DIAG= / =NETLINK_DIAG= | socket inventory |
| =NETFILTER_XT_MARK= / =TUN= | netns restore |
| =MEM_SOFT_DIRTY= | incremental dumps of a large agent heap |
| =USERFAULTFD= | lazy restore pages |

A dump image holds tokens and open-file state. Same-uid only; never
share images. Cap'n sockets should re-dial =GROKOS_SOCK= after restore
instead of assuming FD identity. GPU/CUDA trees are not a CRIU
success path on these profiles.

* ASA seat sample

=0009= adds the router. =0028= builds it as =kernel/sched/asa.o= so
=CONFIG_SCHED_ASA= does not depend on BTF or =SCHED_CLASS_EXT=. Sysfs
is =/sys/kernel/sched_ext/asa/= when sched_ext is on, otherwise
=/sys/kernel/asa/=. =0023= moves sampling onto a freezable workqueue
so PSI and cgroup lookup run in process context, and adds:

| Sysfs | Role |
|-------|------|
| =/sys/kernel/sched_ext/asa/seat_cgroup= | cgroup v2 path; =/= is host PSI |
| =perception= =seat_cgroup= / =seat_descendants= | slice PSI; descendant count is observational |

Write the sessiond user slice (or =asa-router --seat-cgroup auto=).
The kernel holds that cgroup and classifies from its descendant
tasks' runnable count and =nvcsw= plus slice PSI, not host
=nr_context_switches=. =perception= also prints =irq_pct=,
=nr_iowait=, =load1= (Wang Table 1 kernel-visible fields), and
=goal_leaves= (populated =grokos-goal-*= descendants). A nonzero
goal-leaf count adds MIXED and CPU mass. =recommended_scheduler=
wakes pollers via =sysfs_notify= when the cooldown-gated copy
commits. =vote_head= stays in =[0, window)=; writing
=voting_window= keeps the newest samples. =echo 0 > enabled=
cancels the work without taking the sample lock.

Voting follows Wang et al. Algorithm 1: each sample class below
=vote_threshold_pct= is zeroed, remaining mass is weighted
=alpha^{W-t}= (=decay_pct= is =(1-alpha)*100=), and a zero score
vector keeps the previous class. =perception= prints the four =vote_*=
aggregates.

* Workflow tune

Kconfig on/off is the surface. The seat still needs runtime policy for
the workflows that actually run: instant Cap'n, PSI-admitted goals in
bwrap leaves, optional CRIU dump of an agent tree.

| Layer | What it owns |
|-------|----------------|
| Compiled overlay | =CGROUP_FAVOR_DYNMODS=, BORE =MIN_BASE_SLICE_NS=, =0013= migration cost |
| =/usr/lib/sysctl.d/50-linux-rg-grokos.conf= | autogroup off, =max_map_count= / =pid_max= / inotify floors, RT bandwidth cap |
| ASA | =asa-router= writes =seat_cgroup= to the sessiond user slice |
| Per-machine =99-memory.conf= | swappiness, dirty, watermark (laptop zram contract) |
| CRIU dump | =CAP_CHECKPOINT_RESTORE=; do not lower =yama.ptrace_scope= |

Autogroup is off so =grokos-goal-*= =cpu.weight= is visible. =max_map_count=
and =pid_max= are the CRIU/VMA and restore-pid floors. Dirty ratios stay
out of this file so a zram laptop and a RAM-heavy workstation can keep
different writeback contracts. A later =/etc/sysctl.d/99-*= file still
wins on any overlapping key.

=scripts/linux-rg-grokos-tune-check= asserts the packaged sysctl.

* Not a kernel job

- Cap'n schema, peercred userspace, policyd, and scx expert BPF stay
  in userspace.
- EESSI/CVMFS is FUSE + autofs + a userspace repo list
  (=linux-rg-pa8l=), not a new kernel module.
- BTF/pahole is the BPF type blob for packaged kernels, not the seat
  ABI.
