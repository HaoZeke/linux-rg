#+title: linux-rg kernel support for the GrokOS session plane
#+date: [2026-08-19 Wed]

* What GrokOS is (kernel view)

GrokOS is a same-uid two-party vat: =sessiond= exports =Seat=,
=grokos-agent= exports =Agent=, =grokos-shell= exports =Shell=. The
board door is =Seat.spawnAgent= / =Seat.cancelAgent= (schema !20, meta
!68). Cap'n =Goal= / =CancelGoal= and the =grokos-goal= crate are
deleted. Identity is a 32-hex =Util.AgentId=, not a cgroup directory
name.

=cancelAgent= (session !110, meta #104) kills the recorded pid/pgid
and each live child and confirms only when that tree is gone.
=reportAgent= records =/proc/<pid>/stat= starttime and places the pid
in a =grokos-agent-*= leaf (systemd user scope, or a child cgroup
when the parent is delegated). The leaf gets idle =io.prio.class= /
=io.weight= / =cpu.weight= (compile-storm argv can raise a uclamp
cap). Cancel: starttime mismatch means the identity is gone; else
=cgroup.kill= on that leaf, =pidfd_send_signal=, then process-group
=SIGKILL=. Shared =user.slice= is refused. Sessiond's user unit sets
=Delegate=yes= so those leaves can exist under the daemon.

The kernel does not grow a GrokOS syscall. It has to keep the knobs that
plane already uses.

| Seat need | Kernel surface |
|-----------|----------------|
| Spawn admit / defer | =/proc/pressure/{cpu,memory,io}= (=CONFIG_PSI=) |
| Hardware pressure | =/sys/class/{power_supply,thermal,drm,input}= |
| =cancelAgent= tree stop | =kill(pid/pgid, SIGKILL)=; =CONFIG_PROC_CHILDREN= |
| Frequent agent create/destroy | =CONFIG_CGROUP_FAVOR_DYNMODS= |
| Jail (=bwrap --unshare-user/pid/uts/ipc/cgroup=, optional net) | user/pid/uts/ipc/cgroup/net namespaces + tmpfs |
| Session event ring | =memfd_create= |
| Same-uid ACL | =SO_PEERCRED= on =CONFIG_UNIX= |
| Later FS sandbox | Landlock LSM + =CONFIG_SECCOMP= / =SECCOMP_FILTER= |
| Expert scheduler switch | =CONFIG_SCHED_CLASS_EXT= + ASA (=seat_cgroup= PSI) |
| I/O niceness | =io.prio.class= / =io.weight= / =io.latency= (=BLK_CGROUP_IOPRIO=, =IOCOST=, =IOLATENCY=); BFQ group + Kyber available; ADIOS module only |
| CPU share / cap | =cpu.weight= / =cpu.max= (=FAIR_GROUP_SCHED=, =CFS_BANDWIDTH=); autogroup off so those files matter |
| Preempt / util clamp | =PREEMPT_DYNAMIC=, =UCLAMP_TASK_GROUP=; =RT_GROUP_SCHED= off so PipeWire RT is not cgroup-gated |
| memcg writeback | =CGROUP_WRITEBACK= so dirty is per-cgroup once a leaf exists |
| io_uring / time ns / net class | =IO_URING=, =TIME_NS=, =CGROUP_NET_CLASSID= / =NET_PRIO= for tool IO and jail net |
| IRQ-subtracted CPU time | =CONFIG_IRQ_TIME_ACCOUNTING= |
| Optional warm process restore | CRIU (=CONFIG_CHECKPOINT_RESTORE= plus sock-diag / uffd / soft-dirty) |

* Overlay pin

All three profiles (=rgx1gen11.config=, =rgam5terra.config=,
=rgSURFLat.config=) pin the seat set. Arch =config.x86_64= already
enables most of it; the overlay makes =CONFIG_CGROUP_FAVOR_DYNMODS=y=
and repeats the rest so a slim =localmodconfig= cannot drop them.

=scripts/linux-rg-grokos-seat-check= asserts the pin.
=scripts/linux-rg-criu-check= asserts the CRIU set.

Specialized-workflow papers (ghOSt, Shenango/Caladan, Twine, TMO, Heracles,
Firecracker) live in =docs/literature-review.org= under * Specialized-workflow
kernels. They justify userspace policy and the existing cgroup/PSI/sched_ext
pins. They do not add a GrokOS syscall, =PREEMPT_RT=, =isolcpus=, or a
warehouse =io.cost.qos= table.

* CRIU

CRIU (criu.org) freezes a process tree to disk images and restores it.
GrokOS can use that for optional warm restore of a seated agent; cold
resume (session files + Cap'n) stays the default. The kernel job is
the kconfig surface. Dump, restore, and image sealing stay in
userspace.

Overlays pin the official required set as builtins so a
=localmodconfig= cannot drop them and a dump does not depend on
sock-diag modules being loaded:

| Knob | Why CRIU needs it |
|------|-------------------|
| =CHECKPOINT_RESTORE= / =KCMP= / =PROC_CHILDREN= | pid reuse, task compare, children |
| namespaces + =SYSVIPC_SYSCTL= | bwrap jail + IPC restore |
| =FHANDLE= / =EVENTFD= / =EPOLL= | open-by-handle and event fds |
| =UNIX_DIAG= / =INET_DIAG= / =INET_UDP_DIAG= / =PACKET_DIAG= / =NETLINK_DIAG= | socket inventory |
| =NETFILTER_XT_MARK= / =TUN= | netns restore |
| =MEM_SOFT_DIRTY= | incremental dumps of a large agent heap |
| =USERFAULTFD= | lazy restore pages |

A dump image holds tokens and open-file state. Same-uid only; never
share images. Cap'n sockets should re-dial =GROKOS_SOCK= after restore
instead of assuming FD identity. GPU/CUDA trees are not a CRIU
success path on these profiles.

* ASA seat sample

=0009= adds the router. =0028= builds it as =kernel/sched/asa.o= so
=CONFIG_SCHED_ASA= does not depend on BTF or =SCHED_CLASS_EXT=. Sysfs
is =/sys/kernel/sched_ext/asa/= when sched_ext is on, otherwise
=/sys/kernel/asa/=. =0023= moves sampling onto a freezable workqueue
so PSI and cgroup lookup run in process context, and adds:

| Sysfs | Role |
|-------|------|
| =/sys/kernel/sched_ext/asa/seat_cgroup= | cgroup v2 path; =/= is host PSI |
| =perception= =seat_cgroup= / =seat_descendants= | slice PSI; descendant count is observational |

Write the sessiond user slice (or =asa-router --seat-cgroup auto=).
=asa-router.service= starts that command when either ASA sysfs tree
exists. =ASA_SYSFS= / =SCX_LOADER= override the live paths so the
router is testable without a built kernel.
The kernel holds that cgroup and classifies from its descendant
tasks' runnable count and =nvcsw= plus slice PSI, not host
=nr_context_switches=. =perception= also prints =irq_pct=,
=nr_iowait=, and =load1= (Wang Table 1 kernel-visible fields).
=recommended_scheduler=
wakes pollers via =sysfs_notify= when the cooldown-gated copy
commits. =vote_head= stays in =[0, window)=; writing
=voting_window= keeps the newest samples. =echo 0 > enabled=
cancels the work without taking the sample lock.

Voting follows Wang et al. Algorithm 1: each sample class below
=vote_threshold_pct= is zeroed, remaining mass is weighted
=alpha^{W-t}= (=decay_pct= is =(1-alpha)*100=), and a zero score
vector keeps the previous class. =perception= prints the four =vote_*=
aggregates.

* Workflow tune

Kconfig on/off is the surface. The seat still needs runtime policy for
the workflows that actually run: vat =Seat=/=Agent=/=Shell=,
PSI-gated =spawnAgent=, =cancelAgent= process-tree stop, optional
CRIU dump of an agent tree.

| Layer | What it owns |
|-------|----------------|
| Compiled overlay | =CGROUP_FAVOR_DYNMODS=, BORE =MIN_BASE_SLICE_NS=, =0013= migration cost |
| =/usr/lib/sysctl.d/50-linux-rg-grokos.conf= | autogroup off, =max_map_count= / =pid_max= / inotify floors, RT bandwidth cap, =numa_balancing=0 |
| ASA | =asa-router= writes =seat_cgroup= to the sessiond user slice |
| Per-machine =99-memory.conf= | swappiness, dirty, watermark (laptop zram contract) |
| CRIU dump | =CAP_CHECKPOINT_RESTORE=; do not lower =yama.ptrace_scope= |

Autogroup is off so job-leaf =cpu.weight= is visible. =max_map_count=
and =pid_max= are the CRIU/VMA and restore-pid floors. =numa_balancing=0=
because these seats are one memory controller (IISWC 2022 AutoNUMA on
graphs). Dirty ratios stay out of this file so a zram laptop and a
RAM-heavy workstation can keep different writeback contracts. A later
=/etc/sysctl.d/99-*= file still wins on any overlapping key.

=scripts/linux-rg-grokos-tune-check= asserts the packaged sysctl.

* Not a kernel job

The farm's remaining implementables live here, not in a new 00xx:

- Birth =pidfd= from =clone3= + =CLONE_PIDFD= / =CLONE_INTO_CGROUP=
  still belongs in the PTY spawn (shell), not a second open of
  =/proc/<pid>= after the fact. Sessiond already refuses a recycled
  pid via recorded starttime and uses =pidfd_send_signal= plus
  =cgroup.kill= on the =grokos-agent-*= leaf.
- Per-leaf =memory.high= / =cpu.weight= / =io.weight= writes stay a
  sessiond policy choice on that same leaf. Identity stays the 32-hex
  AgentId. Vat should read leaf PSI the way nng already does.
- Landlock + seccomp-bpf per tool/stage (NatiSand RAID 2023). Overlay
  pins the LSMs; sessiond/bwrap must call them. Do not hand-write
  filters.
- systemd-oomd must not SIGKILL one fat session scope. Agent jobs
  are sibling units; compositor/supervisor get omit/avoid.
- Cap'n schema, peercred, policyd, and scx expert BPF stay userspace.
- EESSI/CVMFS is FUSE + autofs + a userspace repo list, not a new
  kernel module. Overlays pin =CONFIG_FUSE_FS=.
- BTF/pahole is the BPF type blob for packaged kernels, not the seat
  ABI.
- Kernel PGO/ThinLTO/AutoFDO is a remote-builder profile, not a boot
  overlay. Do not enable =PREEMPT_RT=, =isolcpus=, ADIOS default, or
  =mitigations=off=.
